# Core Dashboard

เปิด `DWB MCP Studio.exe` หลัง Setup สำเร็จ เปิด Setup ครั้งถัดไปก็จะเข้าหน้านี้ได้เช่นกัน

## ดูอะไรได้บ้าง

- **Tunnel:** สถานะ process และ readiness ของ tunnel-client การแสดงพร้อมไม่ได้แทนการทดสอบเรียกเครื่องมือจาก ChatGPT
- **Broker:** สถานะตัวจัดการ worker และ PID แสดงแยกจาก tunnel เพราะ broker อาจยังมีงานอยู่หลังหยุด tunnel
- **Workers:** จำนวนที่เปิด / จำนวนสูงสุด พร้อมจำนวนที่กำลังเปิดหรือปิด
- **คิว:** จำนวนคำขอรอ worker และคำขอที่กำลังเรียกใช้งาน
- **Sessions:** workspace, worker PID, สถานะ, คิวและเวลาล่าสุด เลือกแถวเพื่อดู session ID และ working directory เต็ม
- **Agents และ Tasks:** แสดง agent ที่ลงทะเบียน, role/capability, สถานะ lease, task ที่กำลังทำ, queue/done count และ priority ของ task โดยอ่านจาก broker snapshot เดียวกัน
- **เหตุการณ์:** เหตุการณ์ core และคำเตือน/ข้อผิดพลาดจาก log ของ DWB tunnel เลือกแถวแล้วคัดลอกรายละเอียดจากช่องด้านล่างได้

สถานะรีเฟรชทุก 3 วินาทีผ่าน named pipe ในเครื่อง โดยไม่ attach session, เปิด worker หรืออัปเดตเวลาใช้งานของ session จึงไม่ขัดกับการคืน worker ที่ว่าง ไม่เปิด HTTP dashboard หรือพอร์ตสาธารณะเพิ่ม

แสดง session สูงสุด 200 แถว และเหตุการณ์ล่าสุดสูงสุด 30 รายการจากส่วนท้ายของ log ไม่ใช่ประวัติครบทั้งหมด เมื่อ broker หยุดหรือตอบไม่ได้ ตารางสถานะสดจะถูกล้าง ไม่ค้างข้อมูลเก่าเป็นสถานะปัจจุบัน

## ปุ่มควบคุม

- **Start MCP:** ถ้ามี Tunnel ID และ key ที่จำไว้แล้ว จะเริ่ม tunnel ให้ หากยังไม่มีจะเปิดหน้ากรอกข้อมูล
- **Stop:** หยุด tunnel ที่ DWB เปิดไว้และ process ลูกของมัน ส่วน shared broker และงานเบื้องหลังของ worker อาจทำงานต่อ
- **ตั้งค่า Tunnel / API key:** แก้ข้อมูลการเชื่อมต่อ หรือกลับ Dashboard ด้วยปุ่มด้านบน
- **ตั้งค่าเครื่อง:** เลือกโฟลเดอร์งาน/จำนวน worker และเตรียมส่วนประกอบใน external

ค่าเริ่มต้นเมื่อปิด Dashboard จะซ่อนลง tray และ MCP ยังทำงาน เปลี่ยนได้ใน **การเปิดและปิดแอป** รวมตัวเลือกเปิดพร้อม Windows และ Start MCP อัตโนมัติ

## อัปเดตจาก beta.9

broker ที่เปิดค้างจากรุ่นก่อนยังไม่มีคำสั่งอ่าน snapshot หาก dashboard แจ้ง “รุ่นเดิม” ให้จบงานและปิด broker ตัวเดิมตามคู่มือ [การอัปเดต](OPERATIONS.md) แล้วเชื่อมต่อใหม่ Dashboard ไม่บังคับปิดงานให้เอง

ช่องรายละเอียดกรองรูปแบบ API key, Bearer token และค่าความลับที่รู้จักก่อนแสดง เป็นการกรองเบื้องต้น ไม่รับประกันว่าข้อความจากโปรแกรมภายนอกไม่มีข้อมูลส่วนตัว ตรวจรายละเอียดก่อนแชร์ภาพหรือข้อความ

## ถาดไอคอนและการปิดหน้าต่าง (beta.12)

เปิด DWB MCP Studio.exe อันเดียว โปรแกรมจะแสดง Setup เมื่อยังไม่พร้อม และ Dashboard เมื่อพร้อมแล้ว ตั้งค่า Tunnel และตั้งค่าเครื่องจากปุ่มด้านซ้ายได้เลย

ค่าเริ่มต้น: กด × หรือย่อจะซ่อนหน้าต่าง แต่คงไอคอน DWB ใน notification area ข้างนาฬิกา ถ้าไม่เห็นให้ดูในลูกศร ^ คลิกไอคอน DWB เพื่อเรียกหน้าต่างเดิมกลับ หรือเปิด EXE เดิมซ้ำก็ได้ การซ่อน Setup ระหว่างติดตั้งปล่อยให้ติดตั้งต่อ ปุ่มยกเลิกใน Setup ใช้ยกเลิกการติดตั้ง

คลิกขวาที่ไอคอน → ออกจากหน้าควบคุม (MCP ยังทำงาน) เพื่อปิด UI และไอคอนถาด กด Stop ใน Dashboard เมื่อต้องการหยุด tunnel ก่อนออก ตั้งแต่ beta.14 เลือกเปิดพร้อม Windows และพฤติกรรมปิด/ย่อได้ที่ **การเปิดและปิดแอป** ดู [รายละเอียด](APP-PREFERENCES-TH.md)
