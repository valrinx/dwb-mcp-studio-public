# การเปิดและปิดแอป — beta.14

เปิด Dashboard → **การเปิดและปิดแอป** หรือคลิกขวาไอคอน N3zuui ข้างนาฬิกา → **การเปิดและปิดแอป…** เลือกแล้วกด **บันทึก**

| ตัวเลือก                  | ผล                                                                                                                |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| เปิด N3zuui พร้อม Windows | เปิดเมื่อบัญชี Windows นี้ลงชื่อเข้าใช้ และเริ่มอยู่ใน tray หาก Setup พร้อมแล้ว                                   |
| Start MCP อัตโนมัติ       | ใช้ Tunnel ID และ key ที่เคยเลือกจำไว้ ต้องเปิดตัวเลือกเริ่มพร้อม Windows ด้วย                                    |
| กด × → ซ่อนไป tray        | เก็บหน้าต่างไว้เรียกกลับ MCP และงานทำต่อ เป็นค่าเริ่มต้น                                                          |
| กด × → ปิดแอปและหยุด MCP  | หยุด tunnel และปิด broker เมื่อไม่มีงานค้าง หากยังมี process/search/คำขอ จะไม่ตัดงานนั้นและแสดงเหตุผลให้จบงานก่อน |
| กด − → ซ่อนไป tray        | เปิดเป็นค่าเริ่มต้น หากปิดตัวเลือกนี้จะย่อไว้ที่ taskbar ตามปกติ                                                  |

หากปิดทั้งหมดไม่สำเร็จ tunnel อาจหยุดแล้ว แต่งานใน broker ยังอยู่ ตรวจสถานะและกด Start MCP เมื่อต้องการเชื่อมกลับไปจบงาน ส่วนเมนู **ออกจากหน้าควบคุม (MCP ยังทำงาน)** ยังคงใช้ปิดเฉพาะ UI ได้

ค่าตัวเลือกอยู่ใน `preferences.json` ภายใน data directory เดิม การเปิดพร้อม Windows ใช้ Run entry ชื่อ **N3zuui MCP Studio** ของบัญชีปัจจุบัน ไม่ต้องใช้สิทธิ์ administrator เมื่ออัปเดตผ่าน Setup โปรแกรมจะเปลี่ยน startup command ไปยัง EXE รุ่นใหม่ให้ หากย้ายโฟลเดอร์เอง ให้เปิด EXE ในตำแหน่งใหม่และบันทึกตัวเลือกอีกครั้งก่อนลบโฟลเดอร์เก่า Windows Startup settings อาจปิดการเริ่มแอปนี้ไว้ได้เช่นกัน

ค่าเริ่มต้นไม่เปิดพร้อม Windows และไม่เชื่อม MCP อัตโนมัติ หากเลือกอัตโนมัติแล้วการเตรียมหรือเชื่อมต่อมีปัญหา โปรแกรมจะแสดงหน้าต่างเพื่อให้ตรวจสอบ ไม่แสดง API key ในข้อความแจ้งเตือน การทดสอบในโครงการใช้ registry แยก ไม่เปิด autostart จริงให้เครื่องที่รันทดสอบ
